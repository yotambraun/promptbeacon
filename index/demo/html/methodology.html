Methodology

The Index measures one thing: how often AI assistants mention a project when asked for recommendations in its category. It does not judge quality, popularity or anything else, and nobody can pay to change it.

What is asked

Each category has a pinned protocol (a JSON file in the repository) with 10 fixed prompts. They are the same for every category, with the category name filled in:

  1. What is the best {category}?
  2. Which {category} should I use for a new project?
  3. What {category} do you recommend?
  4. What are the most popular {category} options?
  5. Compare the leading {category} options.
  6. Which {category} is the most reliable for production use?
  7. What {category} has the best documentation and community?
  8. What is the easiest {category} to get started with?
  9. What are good alternatives to the most popular {category}?
  10. Which {category} do experienced developers prefer?

Each prompt is sent 3 times to each model, so a category gets 90 answers per run.

Models and tier

Models: OpenAI gpt-6-luna, Anthropic claude-haiku-5-5, Google gemini-3.5-flash-lite, at temperature 0.7 (not sent to Claude models, which use their default) and up to 1024 output tokens. The measurement tier is base model: plain API answers from the model's training memory, without web search. It approximates, but does not equal, what people see in ChatGPT, Claude or Gemini apps, which add web search and other orchestration. Model versions are pinned per protocol and change only with a new protocol version, so runs stay comparable.

Counting a mention

An answer mentions a project when the project's name (or one of the listed spellings, such as "Postgres" for PostgreSQL) appears as a whole word. Names that are also ordinary words are matched case-sensitively or by specific spellings (for example "Requests" or requests library, not "HTTP requests"). Each answer counts a project at most once, wherever it appears in the answer.

How ranking works

  • Mention rate = answers that mention the project ÷ successful answers.
  • Rank = 1 + the number of projects with a higher count. Equal counts share a rank (shown with "=").
  • 95% interval: a Wilson score interval for the mention rate. When two projects' intervals overlap ("≈"), the order between them is not statistically clear. The interval treats answers as independent; repeated answers to the same prompt are correlated, so the real uncertainty is somewhat larger.
  • Failed requests are excluded and counted on each page. A run stopped by its budget is marked partial.

Limitations

  • A base model's answers reflect training data with a cut-off date; recent projects can be under-mentioned.
  • Three models and ten prompts are a sample, not every question developers ask. Answers vary between runs, which is why each prompt runs 3 times and intervals are shown.
  • Name matching is literal. A project with a common-word name may be under- or over-counted; the matching rules are in each protocol and the raw answers are published so anyone can check.
  • A mention is not a recommendation: an answer may mention a project to advise against it.

Requests and disputes

Everything happens in public GitHub issues with the index label:

  • Add a project or a category: open an issue with the category, the project and its repository. A project is added when it is open source and is a real alternative in the category; additions take effect in the next run (rankings are never edited by hand).
  • Dispute a result: open an issue pointing at the raw answers. Matching errors are fixed in the protocol and the category is re-measured in the next run; published snapshots are not changed.

Cost

A full run is 2700 answers. Estimated with PromptBeacon's cost estimator from LiteLLM's price map (about 500 output tokens per answer): $1.59 per run, at most $3.24 if every answer used 1024 tokens. Runs are capped with --max-cost.

Reproduce it

pip install promptbeacon
git clone https://github.com/yotambraun/promptbeacon && cd promptbeacon/index
python -m pbindex estimate
python -m pbindex run --max-cost 5 --categories python-http-client
python -m pbindex build

Every snapshot records the SHA-256 of the protocol it used.
