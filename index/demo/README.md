# DEMO: not a measurement, not a ranking

The site in [`html/`](html/) was generated by the real Index pipeline, but from
**PromptBeacon's offline mock model** (canned answers, $0) and with **placeholder
project names** ("Project A", "Project B", ...), so no demo number ever sits next to a
real project. Every page says so in a banner and asks search engines not to index it.

Regenerate it from the `index` directory:

```bash
python -m pbindex run --demo --categories python-http-client,vector-database,static-site-generator --date 2026-11-01
python -m pbindex build --demo
```
